# 折扣代码与屏蔽词管理

- 折扣代码支持中文、字母、数字、下划线和连字符。使用 NFC 和大写规范化，大小写不影响匹配。
- 有效代码唯一；数据库生成列和唯一索引处理并发重复。失效或删除后可重新生成相同文字的新代码，新记录不继承旧记录的使用次数。
- 每人可设不限次数或一次；最多人数可不限或指定。达到最多人数后，整个代码失效，不能通过编辑旧记录重新启用，需要重新生成。
- 永久代码可设置开始时间；临时代码设置开始与结束时间。管理界面显示未开始、生效中和已失效。
- 官网会员页右上角应用代码并更新卡片价格，仅在当前页面内存保留；刷新或离开会员页后重置。确认购买弹窗不再提供代码入口。
- 应用代码只预览折后价格，不检查绑定状态、Staff 身份或购买资格，不创建订单或消耗次数。个人已使用一次的账号仍可预览，确认购买时才校验个人次数和购买资格。
- 折扣代码与普通会员折扣不叠加，采用优惠更高的一项。只有实际采用代码优惠的订单计入用量。
- 服务端购买时重新报价，先锁定折扣记录，再检查人数和个人次数并预留订单。处理中订单占用名额；失败或已补偿订单不占名额；结果不明确的订单保留占用，避免重复扣款和超额。
- 数据库迁移 V17 增加代码、个人次数、人数和活动代码唯一列。迁移随插件启动执行，没有手动改生产数据库。

## 游戏管理指令

`/cctadmin discountcode create <代码或random> <减免百分比> <all或会员> <now或开始时间> <permanent或结束时间> [1或unlimited] [人数或unlimited]`

例如：`/cctadmin discountcode create 周年庆 20 all now permanent 1 100`

`/cctadmin discountcode list`

`/cctadmin discountcode edit <编号> <代码> <减免百分比> <all或会员> <开始时间> <结束时间> [1或unlimited] [人数或unlimited]`

`/cctadmin discountcode delete <编号>`

时间示例：`2026-11-15T12:00`，使用服务器配置时区。

GUI 会员选择页右下角点击命名牌，打开铁砧输入代码，点击结果栏“应用”返回并刷新报价。清空输入后应用可移除代码；确认购买流程沿用当前代码，重新打开会员选择菜单不保留代码。铁砧不消耗经验或物品，阻止提取界面物品。
